# PDF 递归批量解包工具

这个工具会把输入的 `.pdf` 文件依次按 ZIP、7z、RAR 格式尝试，依次使用以下密码：

`lovelili`、`lovelily`、`lililove`、`lililovesmenot`、`Ilovelilinomore`

工具会递归扫描脚本所在文件夹及全部子文件夹中的 `.pdf`。每个起始 PDF 都会独立处理，每层解压后：

- 如果发现 `.mp4`，立即停止并显示文件位置；
- 如果没有 MP4，会递归搜索本层解压出的所有子文件夹；只要任意深度存在 `.pdf`、`.zip`、`.7z` 或 `.rar`，就继续解压；
- 每层严格按 ZIP → 7z → RAR 的顺序尝试，所有格式使用相同的密码规则；
- 每个 PDF 会先在临时目录生成 `.zip` 后缀入口再尝试解压；优先使用硬链接避免复制大文件，原 PDF 不会被改名；
- 如果有多个 PDF/ZIP/7z/RAR，会先尝试体积较大的文件，再尝试其余文件；
- 找到的 MP4 直接复制到起始 PDF 所在文件夹；
- 解压只在临时目录中进行，处理结束后自动清理，不留下层级目录和中间压缩文件；
- 自动纠正旧式 ZIP 中使用 GBK 编码的中文文件名，避免解压后乱码；
- 扫描到的原始 PDF 永远不会被修改或删除；
- 一个起始 PDF 找到 MP4 后，会停止它的递归，然后继续处理批次中的下一个起始 PDF。

## 最简单的用法

把 `pdf_zip_unpacker.py` 放到需要处理的总文件夹中，然后直接双击它。

程序会自行安装缺失的 ZIP/7z/RAR 依赖，递归扫描当前目录及子目录中的全部 PDF。RAR 解压会自动查找 WinRAR 的 `UnRAR.exe`。执行结束后窗口会停留，按回车才会关闭。

最终只会在每个起始 PDF 旁边留下找到的 MP4，不会创建结果文件夹。如果已有内容相同的同名 MP4，程序不会重复复制；如果同名但内容不同，会使用 `_2`、`_3` 等后缀避免覆盖。

## 命令行用法

```powershell
python -m pip install -r requirements.txt
python pdf_zip_unpacker.py                       # 批量扫描脚本所在目录
python pdf_zip_unpacker.py "H:\待扫描文件夹"      # 批量扫描指定目录
python pdf_zip_unpacker.py "H:\路径\文件.pdf"     # 只处理单个文件
```

可选参数：

```text
--max-depth 100      最大递归层数
--max-layer-gb 20    每层解压大小安全上限
```

说明：ZIP 读取并不依赖文件扩展名，因此工具不会真的复制或重命名大型 PDF；直接读取既等效，也避免不必要的磁盘占用。
